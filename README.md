# The Silence Beyond the Universe

Dependency-free static site. Upload ALL files together: `index.html`, `style.css`, `script.js`, `bg.mp4`, `bg.webm`, `poster.jpg`.

## Deploy on GitHub Pages
1. Put all five files in the repo root (or `/docs`).
2. Settings → Pages → deploy from that branch/folder.
3. Open `https://<user>.github.io/<repo>/`. Profile links look like `#/profile/12345678901234567890`; hash routing survives refresh on static hosting.

The video is served from the repo as `bg.mp4` (relative path), not the GitHub viewer URL. If it fails or the user disables it, `poster.jpg` stays as the background.

## How IDs work
IDs are decimal strings validated with `/^\d+$/`, normalized by stripping leading zeros, and incremented with BigInt only for previous/next. A profile is generated by hashing the digit string into a seeded PRNG, so cost grows with digit count, not with numeric value. There is no profile-number cap; the only limit is a 5,000-digit input safety cap (`MAXLEN`).

## Generated vs saved
Generated identities are virtual and reproducible. Edited profiles, favorites, history and settings are stored in `localStorage`: per browser, not shared, not synced. No backend is configured and none is faked. Cross-device saving or shared profiles would require a real backend with auth (e.g. a small API plus database), which is not included.

## Not included
Particle effects, crop tool, gradient overlays, sepia/blur/opacity, photo-style art categories (human portraits, dragons, etc. exist only as the six procedural families), color/style filters and sorting. Only working controls were shipped.
